## 什么是开源

开源是指软件的源代码公开，用户和开发者可以查看代码、了解软件如何工作，并在符合许可的前提下参与改进。

## OneKey 开源了什么

OneKey 官方资料显示，OneKey 硬件钱包的固件和相关软件采用开源方式维护。不同产品的固件代码会保存在 OneKey 的 GitHub 仓库中。

开源不等于用户需要自己看懂代码，也不代表任何软件天然没有风险。它的价值在于代码可以被检查，发布流程也可以被验证。

## 普通用户需要知道什么

OneKey 会通过 GitHub CI 构建固件，并对正式发布的固件进行签名。官方帮助中心还提供了通过校验和比对固件文件与开源代码一致性的验证方法。

对大多数新手来说，使用官方 App、官方固件更新页面和官方 GitHub 仓库即可；不需要在不了解命令的情况下自行修改固件。

本文基于 OneKey 官方公开资料整理，具体仓库、固件版本和验证方法以官方资料为准。
