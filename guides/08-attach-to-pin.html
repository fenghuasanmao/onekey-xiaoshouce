什么是 Attach to PIN

通过不同 PIN 快速进入不同的 Passphrase 钱包。

基于 OneKey 官方公开资料整理阅读指南

功能介绍

Attach to PIN 可以把不同的 PIN 与不同的 Passphrase 钱包绑定。完成绑定后，输入对应的 PIN，就可以直接进入相应的隐藏钱包，不需要每次手动输入 Passphrase。

使用前提

官方帮助中心记录的版本要求为：

  • OneKey Pro 固件 4.15.0 或更高版本；
  • OneKey Classic 1S 固件 3.14.0 或更高版本；
  • OneKey App 5.12.0 或更高版本。

具体要求可能随版本变化，操作前请再次查看官方说明。

OneKey Pro 设置路径

在设备中打开：

设置 → 钱包 → Passphrase → 高级设置 → 绑定 PIN 码

然后输入主 PIN，设置新的 PIN，并为它配置对应的 Passphrase。

Classic 1S 设置路径

在设备中打开：

安全 → Passphrase → 绑定 PIN 码

然后按照设备提示完成主 PIN、新 PIN 和 Passphrase 的设置。

重要提醒

  • 设备的主 PIN 仍然是核心安全保护；
  • 绑定 PIN 只用于进入对应的隐藏钱包；
  • 不要忘记主 PIN、绑定 PIN 和对应的 Passphrase；
  • 连续输错 PIN 可能触发设备自动重置；
  • 使用前建议先确认自己理解隐藏钱包的工作方式。
